# Funkin' Hub

A JavaScript-based central hub and toolkit for *Friday Night Funkin'* modding, web interfaces, and custom tools.

---

## 🚀 Features

* **JavaScript Powered:** Fast, modular, and easy to run on Web or Node.js environments.
* **Asset & Data Management:** Streamlined handling for FNF assets, charts, and song data.
* **Custom Integration:** Easy setup for web utilities, API connectors, or web-based engines.

---

## 🛠️ Prerequisites

Make sure you have the following installed on your machine:

* [Node.js](https://nodejs.org/) (v16.x or higher recommended)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
